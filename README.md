# 🌌 Astronomy & Physics Learning Hub (IOAA Preparation)

Welcome to the Open Educational Resource (OER) for Astronomy, Astrophysics, and Physics!

## 📌 About The Project
This website was built to provide free, high-quality learning materials, past exam solutions, and interactive tools for students preparing for the International Olympiad on Astronomy and Astrophysics (IOAA) and Physics competitions.

- **Live Website:** https://hieulovephysics.framer.website/
- **Creator:** Nguyen Minh Hieu (Hanoi, Vietnam)

- Free study guides & lecture notes
- Physics & Astronomy learning resources
